# For Kavita ❤️ — Princess Day Surprise

Next.js 14 + Framer Motion. All text is in `components/content.js`; photos are `public/images/photo1-10.jpg`.

## Run
    npm install
    npm run dev      # http://localhost:3000

## Music
`public/audio/music.wav` is a soft placeholder. Replace it with your own song (keep the name, or edit the `src` in `components/Experience.jsx`). It never autoplays; it starts when she taps "Open Your Surprise", and the 🎵 button toggles it.

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. vercel.com → Add New Project → import repo → Deploy (defaults are fine).
3. Optional: add env var `NEXT_PUBLIC_SITE_URL` = your final URL, then redeploy.

## Final QR code (after deploying)
- Visit `https://YOUR-SITE.vercel.app/qr` and tap **Download PNG**, or
- `npm run qr -- https://YOUR-SITE.vercel.app` creates `kavita-surprise-qr.png`.
Scan it with a phone camera before printing. Never use a localhost URL.
